# Instruções dos agentes

- Os PRDs devem ser sempre criados na raiz do projeto atual,
  seguindo o formato:
  `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.

- O PRD principal deve permanecer sincronizado com as decisões
  aprovadas para o produto.

- Antes de implementar funcionalidades, consulte o PRD e o SPECS.md.

- Diferencie requisitos confirmados de hipóteses ainda não aprovadas.

- Priorize HTML semântico, navegação por teclado, foco visível,
  contraste adequado e compatibilidade com leitores de tela.

- Não declare que agentes externos executaram tarefas se a revisão
  foi feita apenas por papéis especialistas simulados.

- Documente limitações conhecidas e testes ainda não realizados.

- Evite dependências externas desnecessárias.

- Preserve a privacidade: não adicione rastreamento ou coleta de
  dados pessoais sem aprovação explícita.
