# cacaPalavras# Palavra Secreta

Jogo casual de palavras com três modos:

- Termo: descubra uma palavra por meio do feedback das letras.
- Charadas: resolva enigmas.
- Palavra Misteriosa: descubra a resposta com pistas progressivas.

## Como executar

1. Salve os arquivos na estrutura indicada.
2. Abra o arquivo index.html no navegador.
3. Escolha um dos modos no menu.
4. Digite seus palpites e siga as instruções.

Não é necessário instalar bibliotecas.

## Arquivos

- AGENTS.md: instruções do projeto.
- PRD.md: requisitos do produto.
- SPECS.md: arquitetura e regras técnicas.
- REVIEW.md: revisões e pendências.
- index.html: protótipo jogável.
- docs/plans/2026-10-29-jogo-casual-adivinhacao-palavras.md:
  PRD versionado.
